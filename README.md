## 🎯 Главное за 60 секунд

1. **Не сравниваемся по функционалу.** У 1С функций больше — они на рынке 16 лет, и у нас они и так не победят. Мы выигрываем на **UX, скорости, всё-в-одном, поддержке, темпе развития**.
2. **5 профилей лида на 1С** — каждому свой сценарий продажи: А) выход из франшизы, Б) КОРП с подходящими лицензиями, В) возвращенец, Г) зал без админа, Д) самописная 1С.
3. **Топ-боли клиентов 1С** проверены в 9 интервью: непрозрачный TCO с доплатами, медленная поддержка («такой технической возможности нет»), сложный интерфейс для молодых админов, мессенджеры не работают.
4. **5 готовых офферов** — компенсация остатка лицензии, скидка 10% в 3 дня, финансовая гарантия, AnyDesk-возврат, бесплатный перенос.

## 🔥 Что хочется от ОП после прочтения

1. **Скрипты в работе** — менеджеры используют 10 заходов из [04-cold-outreach.md](04-cold-outreach.md)
2. **TCO-калькулятор в каждой сделке** — на встрече считаем все косты 1С (Mobifitness, Wallet, SMS, доработки) vs наш единый тариф
3. **Дата решения в CRM** — на каждой встрече фиксируем конкретную дату, не «потом напишу»
4. **Кейсы под профиль** — менеджеры знают, какой кейс прислать какому профилю (Fitlab — для денег, GO FITNESS — для триггеров, Brutality — для возвращенцев)
